ReconFSM documentation
======================

**ReconFSM** is a Python-based forensic reconstruction toolkit that models system activity as Finite State Machines (FSM). 
It enables investigators to process timeline logs from disk images, convert them into FSMs, simulate transitions, perform pathfinding analysis, and visualize everything interactively.
