ReconFSM documentation
======================

**ReconFSM** is a powerful forensic reconstruction toolkit that models system activity as Finite State Machines (FSM). 
It enables digital forensic investigators to transform complex timeline logs from disk images into intuitive, interactive FSM models. 
With ReconFSM, you can simulate system transitions, perform deep pathfinding analysis, and visualize digital evidence in a way that makes sense.
