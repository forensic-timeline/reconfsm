Interactive Visualizer
======================

The **ReconFSM Visualizer** is a web-based tool for exploring FSM models. It provides a more dynamic and intuitive way to analyze data compared to static graphs.

Accessing the Visualizer
------------------------

The visualizer is a single-page application located at ``reconfsm/visualizer/index.html``. You can open it directly in your browser:

*   **Local**: File path to ``index.html``.
*   **Web**: [fsm-visualizer.vercel.app](https://fsm-visualizer.vercel.app/)

Features
--------

Loading Data
^^^^^^^^^^^^
You can load any JSON file generated by the ReconFSM converter.
*   **Drag & Drop**: Drop the JSON file anywhere onto the canvas.
*   **File Picker**: Click the "Choose File" button in the sidebar.

Graph Layouts
^^^^^^^^^^^^^
Change how the nodes are arranged to better understand the data:
*   **Force Directed**: Nodes repel each other, good for complex networks.
*   **Hierarchical**: Arranges nodes in levels, great for sequential processes like shutdowns.
*   **Circular/Grid**: Useful for symmetric or organized patterns.

Interactive Pathfinding
^^^^^^^^^^^^^^^^^^^^^^^
In the visualization:
1.  Enter a target state in the search box.
2.  Set the search depth.
3.  Click "Find Path".
The visualizer will highlight the specific branch of the FSM that leads to that target state.

Visual Controls
^^^^^^^^^^^^^^^
*   **Zoom/Pan**: Use the mouse wheel to zoom and drag to move the canvas.
*   **Node Highlighting**: Hover over a node to see its name and connected transitions.
*   **Export**: Export the current view as a high-resolution PNG image for inclusion in forensic reports.

Interface Overview
------------------

The interface is divided into:
1.  **Sidebar**: Data loading and layout controls.
2.  **Breadcrumbs**: Showing the current machine name.
3.  **Canvas**: The main interactive graph area.
4.  **Info Panel**: Details about the selected state or transition.
